# Portfolio Website

## Description
This is my personal portfolio website, created to showcase my design skills, professional background, and featured projects. It serves as a digital resume for potential employers and collaborators.

## Installation & Access
You can access the live website [here](https://marialouisaching.vercel.app/index.html)
Alternatively, explore the project files directly in this GitHub repository.

## Features
- **About Me** – Learn about my background and goals  
- **Contact** – Get in touch via email or LinkedIn  
- **Case Studies** – Detailed walkthroughs of my UX/UI projects  
- **Projects** – A curated list of personal and academic work  
- **Other Work** – Bonus content, explorations, and side projects  

## Skills Utilized
- **Languages & Tools**: HTML, CSS, JavaScript  
- **Design Software**: Figma, Adobe Illustrator
